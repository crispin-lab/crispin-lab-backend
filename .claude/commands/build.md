프로젝트 전체 빌드를 실행한다.

## 절차

1. 인자 확인:
   - `--no-test` 또는 `-x test` → 테스트 제외 빌드
   - 모듈 인자(예: `:lab-space:app`) → 해당 모듈만 빌드
   - 인자 없음 → `./gradlew build` (전체)
2. 실패 시:
   - 컴파일 에러는 출력 그대로 사용자에게 전달.
   - 테스트 실패는 어느 Spec / it 인지 위치를 짚어 사용자에게 전달.
   - 빌드 도중 lint 실패면 `/lint` 사용을 안내.
3. 성공 시 한 줄 요약 (`BUILD SUCCESSFUL in Xs`).

## 룰

- `--no-daemon` 같은 옵션을 임의로 추가하지 않는다 (사용자 환경 존중).
- 캐시를 깨거나 (`--rerun-tasks`) clean 을 묶지 않는다 — 사용자가 명시한 경우에만.
- 출력은 길어도 잘라내지 말고 그대로 보여준다 — 빌드 실패 단서가 묻힌다.
